# MyAI Office artwork

`../MyAIOffice-icon.png` is the app icon and launcher logo. It was generated with the built-in image generation tool from the user's blue-green glass icon reference on 2026-10-15. The same image is packaged as `MyAIOffice.png` and converted to the application's ICNS icon.

Prompt: macOS MyAI Office application icon; four folded glass panes meeting at a central cross, sapphire and cobalt blue left panes, turquoise mint and emerald green right panes; illuminated beveled edges and polished translucent glass; deep blue to teal rounded-square tile; front view, centred, square proportions, minimal padding; no text, letters or watermark; transparent background outside the rounded square.

Module symbols use macOS SF Symbols. Font files from the system and from other installed applications are not copied into the installer.
