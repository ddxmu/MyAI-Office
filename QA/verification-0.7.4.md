# MyAI Office 0.7.4 验收记录

环境：macOS / Apple Silicon，2026-10-16。用户原始业务文件未修改、未上传；本次仅使用本地合成测试工作簿验证界面。

## 本次范围

- MyAI Excel 字体名称框增加右侧下箭头。
- MyAI Excel 字号框增加右侧下箭头。
- 两个控件仍复用原有下拉弹窗、字体列表、字号列表、键盘导航和应用逻辑；箭头与输入值属于同一个可点击控件。

## 测试证据

- `cargo fmt --all -- --check` 通过。
- `cargo clippy -p gridcraft-ui-egui --all-targets --locked -- -D warnings` 通过。
- `cargo test -p gridcraft-ui-egui --lib --tests` 中出现一次既有点选键盘交互用例的非确定性失败；单独重跑该精确用例通过，未修改该测试逻辑。
- 使用最终打包的 MyAI Excel 模块打开本地测试工作簿，并通过应用内截图确认字体框和字号框的下箭头可见；未关闭或操作用户的 WPS 进程。
- 最终应用通过 `codesign --verify --deep --strict`，应用 `Info.plist` 版本为 0.7.4 / build 704。
- 使用 0.7.3 完整包重建 0.7.4 更新结果，目标文件、权限、签名与目标完整 ZIP 一致；损坏包、错误版本、不安全路径和被改动基线均被拒绝。
