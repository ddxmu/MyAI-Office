# MyAI Office 0.6.0 验收记录

验收环境：本机 macOS / Apple Silicon，2026-10-15。测试仅使用自行创建的空白文档。

## 已通过

- 最终套件内的 MyAI Power Point.app 通过系统应用启动机制打开，具有独立应用身份。
- `verify-ppt.py`：点击标题占位框、Text 事件、中文 IME 预编辑和提交、退格、换字体后继续输入、编辑副标题、保存 PPTX 并重新打开。控制接口的文字及按键方法现在进入 egui 事件队列，不再直接写入文档引擎。
- macOS 原生输入：使用当前系统简体拼音输入法，以 System Events 向新建测试进程键入 `zhongwen` 并按空格确认，文档内容为“中文”，截图和测试 PPTX 保存在 `Build/QA/`。此项不是控制接口的文字注入。
- PPT 中文标题占位提示的像素位置测试，以及最终应用的截图检查：文字在占位框内水平、垂直居中。文档中显式选择的中文字体不再被默认 CJK 字体替换。
- Word：通过界面选择宋体、输入中文、将字号改为 18；最终截图中正文中文正常显示。字体名称以中文界面字体显示，常用中文字体置顶，字形示例与名称分开绘制。
- 主界面窗口截图检查：蓝绿玻璃图标、圆角渐变头部、两列圆角卡片、统一左对齐。悬停和柔光动画尊重系统“减少动态效果”设置。
- DeckCraft UI 测试 47 项、文字排版测试 67 项、渲染测试 132 项通过；Word 字体预览测试 11 项通过。
- `verify-update.py`：安装包及更新包 SHA-256、ZIP 完整性、完整包 metadata、0.5.6 加增量重建后逐文件比对、嵌套应用深度签名检查均通过。
- 上游固定源码版本与完整定制补丁能够逆向校验；重复运行 `prepare-sources.sh` 不覆盖本地修改。

## 已知边界

- Word 全部 UI 测试中仍有两项原有失败：`clicks_on_ribbon_and_status_bar_chrome_keep_typing_in_the_document` 的标题样式瓦片断言，以及 `the_default_app_button_shows_only_with_the_hosts_hook` 的旧社区标签断言。结果为 384 通过、2 失败、2 忽略；没有声称整个项目所有测试通过。
- 中文字体使用本机已安装字体或兼容替代，不把微软雅黑等商业字体文件打包分发。其他机器的缺字情况需按其已安装字体另行验证。
- 排版与输入测试覆盖自建回归文档，并不代表所有第三方复杂 PPTX 均能无差异显示。用户截图未附原始 PPTX，未对该原文件做逐页比对。
- 本地签名为 ad-hoc，不是 Apple Developer ID 公证。自动升级重建已验证，未替换正在使用的 /Applications 版本。
