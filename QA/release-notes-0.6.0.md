## 界面升级

- 首页改为蓝绿玻璃风格，使用新的折叠玻璃图标。
- 圆角渐变头部、圆角模块卡片、统一对齐与间距，加入悬停及柔光动效。

## 编辑修复

- 修复 PPT 画布键盘焦点和中文输入法开关，支持点击占位框后直接编辑、打字。
- 修复选择字体、字号后无法继续输入的问题。
- 修复中文占位提示的居中位置和界面中英混排基线；保留显式选择的中文字体。
- 修复 Word 字体下拉列表中文名称显示方框，常用中文字体置顶，字形预览单独显示。
- 重新绘制 Word 字体与字号选择框，统一圆角和边框。
- 四个编辑器采用独立 macOS 应用包启动，改善系统窗口与键盘输入身份。

## 下载与更新

- Apple Silicon / macOS 13 及以上。
- DMG 为拖入 Applications 的完整安装包。
- 从 0.5.6 可使用增量更新；其他版本自动回退完整更新包。
- 本次应用内部结构调整，增量包约 128 MB。下载完成后会校验并安装、重启应用。
- 商业中文字体不随包分发，使用本机已安装字体或兼容替代。
