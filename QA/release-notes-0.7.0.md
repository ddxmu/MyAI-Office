# MyAI Office 0.7.0

- 版本号左侧新增常驻“检查更新”；发现新版本后显示红点和“立即更新”。
- 默认启动时及运行中每 4 小时检查，设置中可以关闭自动检查。
- 下载显示进度条、百分比和已下载/总大小，可取消、失败可重试。
- 加入 BSDIFF40 字节级差分，避免重复下载未变化的编辑器；差分不适用时先询问是否改用完整包。
- 更新前提示保存、关闭办公模块；下载和暂存校验完成后安装并自动重启，新进程确认后显示“更新完成”并清理备份。
- 保留 0.6.1 客户端可识别的小兼容增量包，供第一次升级到新更新器。

注意：0.6.x 的旧更新窗口不会在此次升级前自行变成新界面；升级到 0.7.0 后生效。包大小取决于实际改动，新增大字体/资源不能保证几 MB。本次未改动四个编辑器的文档功能，不包含 LibreOffice；应用仍为本地 ad-hoc 签名，未作 Apple 公证。
