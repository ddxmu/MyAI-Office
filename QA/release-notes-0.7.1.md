# MyAI Office 0.7.1

- 修复 Word 打开文件后，选择宋体、仿宋、黑体等字体时中文正文不随之变化：同步更新东亚字体，不再被导入文档的旧字体覆盖。
- 修复 Excel 中文界面漏加载系统字体的问题，支持中文字体别名、macOS 可选字库、大型中文字体集合，以及字体下拉框输入/选择。
- 私有内嵌 OFL 许可的朱雀仿宋 v0.212，缺少原仿宋时用于兼容显示，不安装到系统，也不提取 WPS/微软字库。
- 实机验证两个编辑器中五种字体的实际字形、选择操作，以及 DOCX/XLSX 保存重开。

更新前请保存文件并退出已打开的 Word、Excel 等模块，再在首页点击“检查更新”。兼容字体并非微软原字库，字形和排版度量可能不同。本次没有更换 PPT/PDF 引擎，不包含 LibreOffice；应用使用本地 ad-hoc 签名，未作 Apple 公证。
