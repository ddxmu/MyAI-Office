# MyAI Office 0.6.1 验收记录

环境：本机 macOS / Apple Silicon，2026-10-16。使用用户明确提供的 DOC 和 XLS 原件的本地只读副本；不上传原件、截图或其中的业务/人员信息。

## 已通过

- DOC：两页横向文档、两个六列表格（11 行和 12 行）正常分行；表头不再和首条数据拼在一起，也不产生多余单元格。固定列宽、底色、单元格边框、垂直对齐、页眉图片/横线和页码字段得到保留。
- DOC → DOCX → 重新打开：两页渲染 PNG 分别逐字节一致，页数仍为 2。最终 release 版本的 Word CLI 和真实编辑器离屏窗口均打开原件验证。
- XLS：两张工作表、61 个非空单元格的值及字体名/字号/粗体逐项对照原件，零差异；合并区域一致。表头填充、边框、对齐、红色文字、扩展主题色与白色填充检查通过。采用原始 Font.weight，而不是不一致的旧 bold 标志。
- GridCraft XLSX 库 175 项测试、UI 92 项测试通过；XLS 导入专项测试通过。新增中文样式、扩展主题色、空白单元格和 XLSX 保存重开回归用例。
- WordCraft DOC 库 71 项测试、布局库 242 项测试通过；新增外部 PAPX、表格属性链、独立行结束标记、边框、CJK 字体默认值、相邻页眉边框合并和字体别名回归测试。
- 变更的 DOC / 布局 / XLSX 库 clippy（all-targets，warnings-as-errors）通过；两个上游定制补丁可反向检查。
- 最终套件内的 Word / Excel CLI 也成功转换两份原件；应用深度签名校验通过。
- 更新包验证通过：DMG / ZIP / 增量包 SHA-256、ZIP 完整性、完整包 metadata，以及 0.6.0 加增量重建后的逐文件一致性和嵌套签名。DMG 215,375,349 字节，增量包 164,227,961 字节。现有增量格式按变化的完整文件打包，重编译编辑器及开放字体使其仍较大，不是字节级差分。

## 已知边界

- 这是对两份真实文件与合成回归用例的验证，不是所有旧格式的兼容承诺。没有取得 WPS 导出的参考 PDF，因此未声称与 WPS 逐像素完全一致。
- 二进制 DOC / XLS 只读导入，编辑后另存为 DOCX / XLSX。XLS 图表、浮动图片/形状、批注等高级对象仍未导入，打开时保留兼容提示。
- 中文字体来自本机已安装字体、开放字体包及兼容替代，不分发微软商业字体；不同机器的字体度量仍可能影响分页。
- 本轮未重跑未变更的 Power Point / PDF 全套测试。Word 全 UI 套件的既有失败见 0.6.0 记录，没有宣称整个上游项目测试全绿。
- 应用使用本地 ad-hoc 签名，非 Apple Developer ID 公证；不替换用户正在运行的 /Applications 应用。
