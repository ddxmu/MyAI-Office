# MyAI Office 0.7.3 验收记录

环境：macOS / Apple Silicon，2026-10-16。原始业务文档不修改、不上传；测试副本、另存文件与页面图仅放在本机忽略目录。

## 本次范围

- DOCX 复杂 HYPERLINK 域原来被压成一个整体文字对象，里面的制表符无法参与排版。现按范围保留文字格式、真实制表符、嵌套 PAGEREF 与域锁定信息，原有点线和右对齐制表位重新生效。
- 中西文字体分别指定时，已识别的中文别名不再仅因发生替代就被忽略。使用系统可用字体或已有开源替代字体，不复制 WPS 字库。
- 不修改业务正文、段落字号、段落标记或分页属性；不硬插分页符，不改全局行距，不启用上版撤回的节网格实验。不自动刷新目录缓存页码。

## 测试证据

- DOCX 242 项通过；新增复杂目录测试修改前失败，修改后通过，并覆盖三次保存重开、格式、制表符、嵌套页码域和指令区嵌套。
- 排版 242 项在正式内置字体配置下通过。原有中文别名用例在该配置下先复现失败，修复别名选择后通过；不是删除测试或只使用没有内置字体的配置。
- DOCX / 排版严格静态检查、格式化、补丁空白检查通过。完整 VendorPatch 在固定原始源码上正向检查、当前自定义源码上反向检查通过。
- 本次提供的 DOCX：七个目录条目的真实制表符、点线及右对齐属性、嵌套 PAGEREF 保留；段落属性、段落标记、样式和节属性未被修复代码改写，原件哈希与测试前相同。
- 四份私有样本分别渲染 4、8、8、2 页，共 22 页，逐页查看；保存重开页数和尺寸不变。新 DOCX 四页像素完全一致；旧 DOC 样本允许整数 EMU 舍入造成至多 2/255 通道差异。
- 实际最终 Word 编辑器另行核对新 DOCX 四页，页面与同一构建原生渲染一致；不能把这一结果称为与 WPS 像素一致。
- Word、Excel 实际字体选择器切换宋体、仿宋、黑体、微软雅黑、楷体，五种字形不同，保存重开仍保持选择。测试自动关闭其自己的临时编辑器，不关闭用户 WPS。
- 构建保留完整 craft-fonts 及已有私有开源字体；未使用或集成 LibreOffice。缺少原有内置字体的中间构建被撤回，未上传。

- 旧样本仍有复杂分页、浮动对象、标题编号、页码文本框等已知差异。字体替代并非原字体等度量替代。
- 这是局部兼容修复，不是 WPS 功能或排版一比一复刻，也不宣称全部旧 DOC / XLS 已达到完全一致。
