# MyAI Office 0.7.0 验收记录

环境：本机 macOS / Apple Silicon，2026-10-16。仅操作独立测试副本，不安装/覆盖 /Applications 中的应用，不读取业务文档。

## 已通过

- 正式构建、Swift 编译、Shell/Python 语法与补丁空白检查；四个未变化的编辑器复用 0.6.1 的模块版本和签名。没有重编译 Rust 引擎或更换字体。
- 完整 DMG：215,444,197 字节；完整自动更新 ZIP：215,689,833 字节。
- 0.6.1 → 0.7.0 旧客户端兼容增量：217,998 字节（约 218 KB）；BSDIFF40 新差分：159,804 字节（约 160 KB）。旧格式兼容包在清单中排在前面，0.6.x 不会误选新格式。
- 使用正式 0.6.1 完整 ZIP 作为基线，两种增量均用客户端同一套代码重建；全部文件 SHA-256、权限与正式 0.7.0 完整 ZIP 一致，嵌套代码签名验证通过。
- 按旧版安装器的文件复制算法另行重建兼容包，结果一致。完整包 metadata、ZIP 完整性、全部资产 SHA-256/字节数验证通过。
- 不安全相对路径、错误目标版本、损坏的目标哈希、被修改的基线均被拒绝；失败暂存被清理，原始基线保持逐文件一致。
- 独立副本实机界面验收：检查最新版本、服务器 503 后重试、新版本提示、“稍后”后保持更新入口、百分比/下载大小及进度条、取消后原版本不变。
- 使用本地限速服务器，测试副本 0.7.0 → 测试 0.7.1：真实下载差分、重建/校验、替换、启动新进程、显示“更新完成”；新进程回执确认后才清理旧版备份。0.7.1 只用于本地测试，不是公开发版。
- 实机下载/更新入口/完成截图保存在 Build/QA/update-ui，未把截图或任何用户业务文件上传仓库。

## 边界

- 启动检查及每 4 小时 Timer 已实现，设置可关闭自动检查；本轮未实际等待 4 小时，不能声称验证了完整墙钟周期。
- 0.6.x 必须先用原来的升级方式升到 0.7.0，之后才能看到新入口、百分比和安装回执界面。
- 差分不适用时先征求确认再下完整包；大规模增加字体、图片或更换引擎时，不能保证任何版本都在几 MB。
- 新版无法确认启动时保留旧版备份并报错，不把“系统接受启动命令”当成成功启动；本轮没有人为制造系统拒绝启动的回退情形。
- 应用使用本地 ad-hoc 签名，未作 Apple Developer ID 公证；本轮没有修改 DOC/XLS/PPTX/PDF 编辑功能，也不宣称重跑了四个编辑器全套测试。
